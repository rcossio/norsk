# Ankeret

Entrenador de vocabulario noruego (bokmål) para hispanohablantes, basado en anclas
mnemotécnicas hacia el inglés, italiano, francés, portugués y castellano.

107 palabras, 18 frases, 10 modos de juego. Un solo archivo HTML, sin dependencias
ni build. Audio generado con [Piper](https://github.com/rhasspy/piper)
(voz `no_NO-talesyntese-medium`), con fallback al sintetizador del navegador.

Publicado en https://rcossio.github.io/norsk/
